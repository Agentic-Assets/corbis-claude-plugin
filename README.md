# Moved: Corbis plugin

This repository is retired. The Corbis plugin for Claude, Codex, and Cursor now lives at
[Agentic-Assets/corbis-mcp](https://github.com/Agentic-Assets/corbis-mcp), under the plugin
name `corbis`. It includes the same research skills (literature review, citations, and
paper review) and the Corbis research connector.

The earlier `corbis-research-skills` plugin published here is replaced by `corbis`. If you
installed it locally, remove it and install `corbis` from the new repository.
